# Modèle OSI et TCP/IP

Le modèle OSI a sept couches : physique, liaison, réseau, transport, session, présentation, application. En pratique on utilise le modèle TCP/IP à quatre couches.

TCP établit une connexion avec la poignée de main en trois temps : SYN, SYN-ACK, ACK. Un balayage de ports envoie des SYN sur de nombreux ports pour découvrir les services ouverts.

UDP est sans connexion : plus rapide mais sans garantie de livraison, utilisé par DNS et le streaming. #réseau
